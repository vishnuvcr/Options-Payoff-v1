# Phase 9G cross-source H1 sensitivity

The same frozen H1 strategy, same 0.25% slippage and ₹20/order cost model, and the same broad calendar years produce different realized results across two independent option datasets.

2024: HF source ₹20,656.83 over 26 realized trades; Rissin ₹18,690.31 over 9 realized trades.
2026: HF source ₹21,014.63 over 14 realized trades; Rissin ₹58,226.92 over 18 realized trades.

The 2026 net difference is ₹37,212.29. This does not establish that either source is more correct; it establishes that vendor/source construction and coverage materially affect measured strategy economics. Final inference must therefore report source provenance and avoid silently mixing source periods.

The H2/H3 horizon comparison should use the same source within each comparison. Cross-source pooled comparisons are prohibited unless measurement equivalence is demonstrated.
